# Decision register (§32.3)

Safe, reversible defaults were chosen for non-blocking decisions so delivery could proceed. Items marked **Owner** need business confirmation; **Legal/Technical** items must be validated by qualified professionals before production. Configurable values live in `public.business_rules` (versioned, audited) and can be changed with `set_business_rule` without a code release.
